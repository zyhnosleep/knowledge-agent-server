# 03 — 文本提问场景（@ 提问 → 异步回答）

**What to build:** 群里 @ 机器人并发送纯文本问题时：先回"处理中"占位回执 → 后台对 `feishu-inbox` 项目发起问答 → 完成后向同一会话推送答案（含引用信息）；问答超时或失败 → 回执明确原因。答案适配飞书消息限制（长度截断/格式裁剪），问题过短或无实质内容 → 回执提示。占位回执与最终答案在逻辑上关联（用户可辨认是同一次提问的回复）。

**Blocked by:** 01 — 平台配置清单 + 长连接事件通路（骨架）

**Status:** ready-for-agent

- [x] @ 机器人 + 问题 → 先收"处理中" → 后收答案（带引用来源，引用文档标题去重）
- [x] 答案基于 `feishu-inbox` 项目检索，不混入其他项目语料（project_slug 固定传 feishu-inbox）
- [x] 问答超时 → 回执明确失败（status=timeout → "问答超时"）
- [x] 后端问答异常 → 回执明确失败原因（status=error/max_steps 或 API 异常）
- [x] 答案过长 → 截断至 4000 字符（带截断标记）
- [x] 无实质内容的问题（纯 @ 无文字）→ 回执提示提问示例
