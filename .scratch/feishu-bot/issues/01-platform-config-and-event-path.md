# 01 — 平台配置清单 + 长连接事件通路（骨架）

**What to build:** 飞书机器人的第一发 tracer bullet——打通"群里 @ 机器人 → 立即收到回执"的完整通路。交付：(a) 飞书开放平台配置清单文档（机器人能力、长连接接收 `im.message.receive_v1`、发消息权限、下载文件权限、租户校验配置），供人工照做；(b) 长连接客户端（WebSocket 连接飞书开放平台，断线自动重连、心跳保活）；(c) 事件解析（区分文本消息/文件消息/@ 提及，解析发送者与群信息）；(d) 租户限定 + 可选群白名单过滤（配置存在才收紧）；(e) 基础回复能力（向同一会话发消息，先回固定"收到，处理中"回执）；(f) dev 环境部署（常驻进程 + 开机自启 + 崩溃自愈 + 环境配置项接入）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 平台配置清单文档交付（docs/agents/feishu-bot-setup.md：机器人能力/权限/长连接订阅/群拉入/环境配置）
- [x] 长连接稳定运行：断线自动重连（reconnect_delay 退避，测试覆盖）、进程崩溃自动拉起（systemd Restart=on-failure）
- [x] 群里 @ 机器人 → 收到占位回执（T3 起为"处理中…"；T1 验收的"收到，处理中"随场景演进）
- [x] 非本租户 / 非白名单群的 @ 消息被忽略（不回复、不处理）
- [x] 无 @ 的群消息不触发任何响应（mentions_bot 检查）
- [x] 部署可审计：logger 记录连接建立/断线重连/事件丢弃/启动失败全过程
