# 全局项目切换器设计

**日期：** 2026-07-14  
**状态：** 已由用户通过效果图确认

## 目标

让 `internal-research`、`agent` 等项目在新版工作台中重新可见、可切换，并确保运行看板、文档库、聊天历史和项目统计始终使用同一个项目范围。

## 视觉基准

效果图：`C:/Users/响睡觉/.codex/generated_images/019f5e69-960c-75e1-875c-aaa93cd1d4a3/exec-031ed330-e4ea-4d01-aa59-365550844993.png`

- 侧栏底部固定“当前项目”选择器，显示项目名、绿色在线点和展开箭头。
- 运行看板说明文字与指标之间放置 48px 高的紧凑项目标签栏。
- 当前标签使用深色轻抬升背景、绿色下划线和绿色状态点；不恢复大型项目卡片。
- 标签栏右端显示 `PROJECT SYNCING` / `PROJECT SYNCED`，采用 10px 等宽字和克制的绿色。
- 保持现有近黑背景、纸白文字、细分隔线、衬线大标题与开放式布局。

## 行为

1. 项目从 `/api/projects?limit=200` 加载后，同时渲染侧栏选择器和运行看板标签。
2. 任一入口切换项目时，清除文档级范围、当前会话和临时附件。
3. 切换不跳转页面；当前页面的数据就地刷新：
   - 运行页：指标、处理队列、右侧概览、最近事件。
   - 文档库：上传目标、统计和文档列表。
   - 聊天：项目标题、历史会话和欢迎态。
4. 选择保存到 `localStorage` 的 `night-research-active-project`；刷新后优先恢复。
5. 若已保存项目已被删除，则选择 API 返回的第一个项目并覆盖旧值。
6. 切换期间禁用两个入口并显示 `PROJECT SYNCING`；所有当前页面刷新完成后显示 `PROJECT SYNCED`。
7. 项目加载或刷新失败时恢复可操作状态，显示 `PROJECT SYNC FAILED`，不删除当前页面已有内容。

## 响应式

- `> 768px`：侧栏选择器和横向标签同时可见。
- `≤ 768px`：侧栏折叠，因此只显示可横向滚动的项目标签。
- 项目名超长时单行省略；控件不得制造页面横向溢出。

## 验收

- 项目 `agent` 可从两个入口选择。
- 切换后四类数据均使用 `project_slug=agent`。
- 刷新后仍选中 `agent`。
- 删除或失效的保存值可安全回退。
- 键盘可聚焦选择器与标签；选中状态通过文字、下划线和 `aria-selected` 同时表达。
- 现有上传、对话、原文回溯和删除功能不回归。
